گرفتن خروجی DXF از فایل DWG

Exporting a DXF File from DWG

راهنمای گام‌به‌گام برای تبدیل فایل‌های نقشه‌کشی DWG به فرمت قابل‌تبادل DXF، با استفاده از AutoCAD، ابزار رایگان DWG TrueView یا مبدل‌های آنلاین.

A step-by-step guide to converting DWG drawing files into the exchangeable DXF format, using AutoCAD, the free DWG TrueView tool, or an online converter.

01 / چرا DXF؟/ why dxf

فرمت DXF چیست و چه زمانی لازم است؟

What is DXF, and when do you need it?

DXF (Drawing Exchange Format) یک فرمت متنی و باز است که توسط اتودسک برای اشتراک‌گذاری داده‌های نقشه بین نرم‌افزارهای مختلف طراحی شده است. برخلاف DWG که یک فرمت بسته و اختصاصی است، اکثر نرم‌افزارهای CAD، CAM و GIS می‌توانند فایل‌های DXF را بدون مشکل باز کنند.

DXF (Drawing Exchange Format) is an open, text-based format created by Autodesk to share drawing data between different software packages. Unlike DWG, which is a closed, proprietary format, most CAD, CAM, and GIS applications can open DXF files without compatibility issues.

02 / روند کلی/ overview

روند کلی تبدیل، در ۴ گام

The conversion process, in 4 steps

  1. فایل DWG را در نرم‌افزار CAD مورد نظر خود باز کنید.
    Open the DWG file in your CAD application of choice.
  2. از منو گزینه Save As یا Export را انتخاب کنید.
    Choose Save As or Export from the menu.
  3. از لیست فرمت‌ها، .dxf و نسخه (Version) مناسب را انتخاب کنید.
    From the format list, select .dxf and the appropriate version.
  4. فایل را ذخیره کرده و در صورت نیاز، آن را در نرم‌افزار مقصد باز کنید تا از صحت خروجی مطمئن شوید.
    Save the file, then open it in the target application to confirm the export is correct.
03 / روش‌ها/ methods

سه روش برای گرفتن خروجی DXF

Three ways to export DXF

روش اول — AutoCAD

Method 1 — AutoCAD

نیاز به لایسنس licensed software
  1. فایل DWG را در AutoCAD باز کنید.
  2. دستور SAVEAS را در خط فرمان بنویسید، یا از مسیر File › Save As استفاده کنید.
  3. در کادر «Files of type»، فرمت AutoCAD DXF (*.dxf) و نسخه مناسب (مثلاً 2018 یا R12) را انتخاب کنید.
  4. نام و محل ذخیره را مشخص کرده و روی Save بزنید.
  1. Open the DWG file in AutoCAD.
  2. Type the SAVEAS command, or go to File › Save As.
  3. In "Files of type", pick AutoCAD DXF (*.dxf) and the matching version (e.g. 2018 or R12).
  4. Set the file name and location, then click Save.

روش دوم — DWG TrueView

Method 2 — DWG TrueView

رایگان free

اگر AutoCAD ندارید، ابزار رایگان DWG TrueView از اتودسک همین کار را به‌سادگی انجام می‌دهد.

If you don't have AutoCAD, Autodesk's free DWG TrueView tool does the same job.

  1. DWG TrueView را نصب و اجرا کنید و فایل DWG را باز کنید.
  2. از منو File › Save As را انتخاب کنید.
  3. فرمت DXF و نسخه دلخواه را انتخاب و ذخیره کنید.
  1. Install and open DWG TrueView, then open the DWG file.
  2. Go to File › Save As.
  3. Choose the DXF format and desired version, then save.

روش سوم — مبدل آنلاین

Method 3 — Online converter

بدون نصب no install

برای تبدیل سریع و بدون نصب نرم‌افزار، می‌توان از مبدل‌های آنلاین DWG به DXF استفاده کرد.

For a quick conversion without installing anything, an online DWG-to-DXF converter can be used.

  1. فایل DWG را در وب‌سایت مبدل آپلود کنید.
  2. فرمت خروجی DXF و نسخه را انتخاب کنید.
  3. فایل تبدیل‌شده را دانلود کنید.
  1. Upload the DWG file to the converter's website.
  2. Select DXF as the output format and choose a version.
  3. Download the converted file.
توجه note برای فایل‌های محرمانه یا پروژه‌های حساس، از آپلود در سرویس‌های آنلاین ناشناس خودداری کنید. Avoid uploading confidential or sensitive project files to unfamiliar online services.
04 / انتخاب نسخه/ choosing a version

کدام نسخه DXF را انتخاب کنم؟

Which DXF version should I choose?

نرم‌افزار مقصد تعیین می‌کند کدام نسخه را باید انتخاب کنید. نسخه‌های قدیمی‌تر سازگاری بیشتری دارند اما ممکن است برخی عناصر جدید را پشتیبانی نکنند.

The target software determines which version to pick. Older versions are more broadly compatible but may not support newer drawing elements.

نسخهVersion مناسب برایBest for
R12 حداکثر سازگاری با نرم‌افزارهای قدیمی و GIS Maximum compatibility with legacy and GIS software
2004 – 2010 اکثر نرم‌افزارهای CAD متداول Most common CAD applications
2013 – 2018 نسخه‌های جدیدتر با پشتیبانی از عناصر پیشرفته Newer software, supports advanced elements
05 / نکات مهم/ good practice

نکاتی پیش از ذخیره‌سازی

Things to check before saving

  1. واحدها را بررسی کنید: مطمئن شوید واحد ترسیم (میلی‌متر، متر یا اینچ) با نرم‌افزار مقصد یکسان است.
    Check units: make sure the drawing units (mm, m, or inches) match what the target software expects.
  2. لایه‌ها (Layers) را مرور کنید: DXF لایه‌ها را حفظ می‌کند، اما نام‌گذاری متفاوت ممکن است در نرم‌افزار مقصد به‌هم بریزد.
    Review layers: DXF preserves layers, but naming conventions may look different once opened in the target software.
  3. بلوک‌های پیچیده را در نظر بگیرید: برخی نرم‌افزارها بلوک‌های تودرتو یا External References را به‌درستی نمی‌خوانند؛ در صورت نیاز آن‌ها را Explode کنید.
    Watch complex blocks: some applications don't read nested blocks or external references correctly; explode them first if needed.

سوالات متداول

Frequently asked questions

This is usually caused by a DXF version mismatch or a difference in drawing units. Try an older version and double-check the units.
