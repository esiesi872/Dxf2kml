# جعبه‌ابزار CAD/GIS

یک صفحهٔ ورودی (Landing Page) که به چند ابزار تبدیل فرمت نقشه متصل می‌شود. همه‌چیز کاملاً در مرورگر اجرا می‌شود (بدون سرور یا بک‌اند).

## ساختار فایل‌ها

```
/index.html              ← صفحهٔ اصلی (فهرست ابزارها)
/favicon.svg
/robots.txt
/sitemap.xml
/dxf2kml/index.html      ← ابزار فعال: DXF → KML
```

هر ابزار در پوشهٔ مخصوص به خودش قرار می‌گیرد تا آدرس اینترنتی جدا و تمیزی داشته باشد، مثلاً:
`https://<username>.github.io/dxf-to-kml/dxf2kml/`

وقتی دو ابزار دیگر (KML/KMZ → DXF و KML/DXF/KMZ → TXT) را برایم بفرستید، به همین شکل در پوشه‌های `kml2dxf/` و `kml2txt/` اضافه می‌شوند و کارت‌های «به‌زودی» در صفحهٔ اصلی به لینک واقعی تبدیل می‌شوند.

## راه‌اندازی روی GitHub Pages

1. یک ریپازیتوری جدید در گیت‌هاب بسازید (مثلاً به نام `dxf-to-kml`).
2. کل ساختار پوشه‌ای بالا (شامل پوشهٔ `dxf2kml`) را در ریشهٔ همان ریپازیتوری آپلود کنید.
3. به بخش **Settings → Pages** ریپازیتوری بروید.
4. در قسمت **Source**، شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب کنید و ذخیره کنید.
5. بعد از حدود یک دقیقه، سایت روی آدرسی شبیه این در دسترس خواهد بود:
   `https://<username>.github.io/dxf-to-kml/`
   و ابزار DXF→KML روی: `https://<username>.github.io/dxf-to-kml/dxf2kml/`

## مهم: جایگزینی آدرس سایت (برای سئو)

در `index.html` (ریشه)، `dxf2kml/index.html`، `robots.txt` و `sitemap.xml`، آدرس نمونهٔ `https://your-username.github.io/dxf-to-kml/` قرار داده شده. بعد از فعال‌سازی GitHub Pages، این آدرس نمونه را در همهٔ این فایل‌ها با آدرس واقعی سایت خودتان جایگزین کنید.

## زبان سایت

هم صفحهٔ اصلی و هم ابزار DXF→KML دو زبانه هستند (فارسی/انگلیسی). انتخاب زبان در `localStorage` مرورگر ذخیره می‌شود، پس اگر کاربر زبان را در یک صفحه عوض کند، همان انتخاب در صفحات دیگر سایت هم حفظ می‌شود.

## راهنما و درباره

- در صفحهٔ اصلی: فقط دکمهٔ «درباره» (اطلاعات توسعه‌دهنده) وجود دارد.
- در صفحهٔ ابزار DXF→KML: دکمه‌های «راهنما» (نحوهٔ استفاده از همان ابزار)، «درباره»، و «خانه» (بازگشت به صفحهٔ اصلی).

## ابزار DXF → KML

### سیستم مختصات
- **UTM** (پیش‌فرض، با زون پیش‌فرض ۳۹): باید شمارهٔ زون (۱ تا ۶۰) و نیمکره (شمالی/جنوبی) را وارد کنید. مختصات X و Y فایل به‌عنوان Easting و Northing خوانده می‌شوند و با فرمول استاندارد UTM → WGS84 به طول/عرض جغرافیایی تبدیل می‌شوند.
- **جغرافیایی (WGS84)**: برای فایل‌هایی که از قبل مختصات X/Y آن‌ها طول/عرض جغرافیایی است.

### محدودیت‌های فعلی
- عناصر پشتیبانی‌شده: `LINE`, `POINT`, `CIRCLE`, `ARC`, `LWPOLYLINE`, `POLYLINE`, `TEXT`, `MTEXT`.
- عناصر پیچیده‌تر مثل `INSERT` (بلوک‌ها)، `SPLINE`، `HATCH` و ابعادگذاری (`DIMENSION`) در حال حاضر پشتیبانی نمی‌شوند.
- سیستم‌های مختصات دیگر (مثل State Plane یا سیستم‌های محلی/دلخواه) پشتیبانی نمی‌شوند؛ فقط UTM و WGS84.
